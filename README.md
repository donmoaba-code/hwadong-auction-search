# 화동경매 검색툴

화동옥션 / 화동양행 원본 검색을 새 창으로 여는 브라우저 검색 도우미입니다.

## 사용

GitHub Pages 배포 후 아래 URL로 접속합니다.

`https://<GitHub사용자명>.github.io/hwadong-auction-search/`

1. 검색 대상(화동옥션 / 화동양행) 선택
2. 검색어 입력
3. **검색 (원본 새 창)** 클릭

한글 검색어는 필요 시 한자 후보로 변환해 미리보기에 표시합니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 검색 UI |
| `hanja_convert.js` | 한글↔한자 변환 |

정적 페이지만으로 동작합니다. 별도 서버 설치가 필요 없습니다.
